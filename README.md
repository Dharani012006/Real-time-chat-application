# Real-Time Chat Application

## Description

A real-time web-based chat application developed using Java and Spring Boot. The application enables users to exchange messages instantly through WebSocket communication.

## Features

- Real-time messaging
- WebSocket communication
- STOMP messaging protocol
- Typing indicator
- Message timestamps
- User name display
- Persistent message history
- H2 database integration
- Simple and responsive chat interface

## Technologies Used

- Java
- Spring Boot
- WebSocket
- STOMP
- SockJS
- Spring Data JPA
- H2 Database
- HTML
- CSS
- JavaScript
- Maven
